🧭 PathForge

Build Skills. Build Projects. Build Your Career.

PathForge is a student-focused technology career companion built with Python and Streamlit. It brings career exploration, project ideas, useful APIs, internships, learning platforms, and developer resources together in one simple dashboard.

✨ Features
🎯 Career Target

Choose your target technology role and use PathForge to explore resources relevant to your career direction.

PathForge includes roles across:

🤖 Artificial Intelligence & Machine Learning
📊 Data Science & Analytics
💻 Software Engineering
🌐 Full-Stack & Web Development
☁️ Cloud & DevOps
🔐 Cybersecurity
🗄️ Databases
⛓️ Blockchain & Web3
🔌 IoT & Embedded Systems
🧪 QA & Testing
🚀 Product & Technology
And many more
🚀 Project Explorer

Explore practical portfolio projects organized by career role.

Each project includes:

Project title
Project description
Relevant GitHub repository
Role/category classification

You can search projects and filter them by role.
